# Deep Learning-Based Multi-Class Body Fluid Cell Type Classification

## A Comparative Evaluation of Image Enhancement Techniques

This repository contains the source code for the research project:

> **Deep Learning-Based Multi-Class Body Fluid Cell Type Classification: A Comparative Evaluation of Image Enhancement Techniques**

## Repository Contents

This repository includes the following main components:

* Data augmentation
* Image filtering
* Image classification models

## Data Augmentation

Code for data augmentation used in the research.

## Image Filtering

Code for image filtering techniques.

## Image Classification Models

The following deep learning models are included:

* MobileNetV3Large
* DenseNet121
* ResNet50
* EfficientNetB3
